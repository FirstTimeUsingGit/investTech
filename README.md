# 三個價

畀完全未接觸過投資、亦唔識寫程式嘅人用。打開瀏覽器，輸入股票代號，就會見到三個大數字：

1. **建議買入價**
2. **目標賣出價**
3. **止損價**

跟住用日常廣東話解釋點解係呢幾個價，以及用咗邊啲指標（20／50天平均線、波段高低、ATR）。可以覆盤舊日子，唔使真金白銀。

不是投資建議，數字來自技術分位，只供學習。

## 點樣喺自己電腦打開

你只需要做三次動作（用 Mac 或者 Windows 都得）：

1. 安裝 [Node.js](https://nodejs.org/)（揀 LTS 版本）。
2. 打開「終端機」（Mac）或者 PowerShell（Windows），進入呢個資料夾。
3. 輸入下面兩行，每次輸入完撳 Enter：

```bash
npm install
npm run dev
```

之後瀏覽器打開提示嘅網址（通常係 `http://localhost:3847`）。見到「三個價」就可以開始搜尋，例如 `0700.HK` 或者 `AAPL`。

**唔使申請 API 鎖匙，亦唔使登入。** 未連接時用 Yahoo Finance 延遲行情，三個價、圖表、詞彙同覆盤全部都可以用。

## 連接 Longbridge（可選）

想用即時港股／美股報價，撳右上角「連接 Longbridge」，用你嘅 Longbridge 戶口授權。

- 用 OAuth 2.0 + PKCE（公開客戶端，冇 App Secret）。
- 只申請行情相關權限（報價、訂閱、靜態資料）。**唔會申請交易／落盤權限。**
- 美股 LV1 包盤前、盤中、盤後、夜盤；夜盤要喺行情連線授權時打開。港股冇夜盤／盤前。
- Refresh token 只存在伺服器（本機預設 `.data/`；Vercel 等唯讀檔案系統用 `/tmp` 同記憶體）。OAuth 進行中嘅狀態放 httpOnly cookie，唔會傳到頁面 Javascript。檔案寫唔入亦唔會令搜尋／三個價當機。
- 授權畫面如果出現交易權限，請取消剔。
- 解除連接之後會自動返 Yahoo 延遲行情。

如果你喺雲端或者反向代理後面開呢個 app，可以設 `LONGBRIDGE_PUBLIC_ORIGIN`（例如 `https://your-host.example`），OAuth 回跳網址會用呢個網域。

## 入面有咩

- 港股同美股同一個搜尋框（700、0700、0700.HK、AAPL 都識）
- 股票頁：三個價、計劃一句、圖表、指標解釋、詞彙
- 覆盤：揀舊日期，只用當日或之前嘅資料，然後逐日播放
- 詞彙同「點用」
- 觀察名單存在你部瀏覽器（localStorage）
- 可選 Longbridge 即時行情；Yahoo 永遠係後備
- 連接之後，美股現價跟盤前／盤中／盤後／夜盤最新一筆；港股仍然係盤中報價

## 唔包括

落盤、戶口結餘、即時推送盤口、新聞、當日炒賣、期權。呢個 app **唔會呼叫** Longbridge 交易／訂單／資金 API。

## 開發者指令

```bash
npm run dev      # 開發伺服器，port 3847
npm run build    # 生產建置
npm run test     # 單元測試（計價、覆盤、代號轉換）
```
